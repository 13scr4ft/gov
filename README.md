# Gov Wallet Demo

A Flutter UI prototype inspired by the screenshots supplied in the prompt.

## Important
This is a **demo/prototype**, not an official government application and does not contain valid identity credentials. All identity data shown in the app is fictional.

## Run
1. Install Flutter.
2. Extract the project.
3. Run `flutter pub get`.
4. Run `flutter run`.

The project intentionally uses only Flutter SDK widgets and Material icons, so there are no extra runtime packages.
